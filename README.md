# IELTS Study Lab

A self-contained, responsive English presentation website about effective IELTS study strategies.

## Features
- Eight presentation slides with a clean monochrome design.
- Clickable slide navigation, previous/next controls, and progress bar.
- Click underlined vocabulary to see Vietnamese meaning, IPA transcription, example sentences, and browser text-to-speech pronunciation.
- Keyboard navigation with left/right arrow keys.
- Mobile-friendly layout.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `ielts-study-lab`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

Pronunciation audio uses the browser's built-in speech synthesis. Available voices can differ by device and browser.
